01ENVIRONMENT

Learn actuator decisions inside a GNC loop

The agent controls the orientation of a rigid body through four reaction wheels. Guidance abstraction provides a target attitude and angular rate. A state estimator and fault-management path supply the controller’s belief about body's position and attitude. An RL agent learns to turn that information into motor commands.

The simulator is implemented in phases, each time another abstraction is added: base satellite physics; envoronment vectorization; wheels faulure modes; sensors measurements replace ground truth from physics; signal/device degradation or complete loss; supervisor modes; mission scenarios; orbital configuration. The physics at 100 Hz, sensors measurements at range from 80 to 100Hz, executes control at 20 Hz, with 512 parallel environments configured for training and evaluation. This describes batching, not a measured throughput result.

Partial observability is deliberate: delayed measurements, estimated gyro bias, and inferred actuator authority replace direct access to the simulator’s state. The current agent is feedforward. Previous actions and explicit estimates provide context; there is no recurrent memory in the published network shape.

02TRAINING HISTORY

Imitation learning: PD controller as a teacher

Along the training process it was gradually shifted what the algorithm was responsible for controlling. Fundamentally changing the action space of the neural network across three distinct phases. The early sequence began with residual PD: learn a small correction above PD controller. It then moved to direct body-torque, where an agent had to calculate the total rotational force needed along the three physical axes of the satellite's body. Ultimately direct wheel-motor control, where an agent directly commanding the individual voltages/currents of the four physical reaction wheel motors. These are changes in action space and responsibility.

A useful practical step was supervised initialization from the PD teacher. RL algorithms training from scratch struggles at the very beginning because an untrained NN takes completely random actions, leading to crashes and slow learning.An imitation learning helps to bypass this problem. Data were collected from trajectories of untrained, partly trained, and trained residual policies, then paired with teacher actions. The policy mean was passed through tanh and fitted using mean-squared error to those actions. This gave the Actor-Critic network a solid baseline behavior. It guaranteed that an agent started its training already knowing how to stabilize the satellite decently well, ensuring it explored useful states rather than flailing randomly.

L_imitation = mean(tanh(μθ(o)) − A_teacher)²

That initialized the actor–critic network before further RL experiments in direct control. The benefit is a useful initial behavior and state coverage. It is not a guarantee that imitation transfers across action spaces. A three-component torque teacher cannot blindly copy a 3-component output from a teacher into a 4-component motor output head without explicitly designing a mathematical mapping matrix to translate those targets. Imitation learning gives a great head start, but it does not automatically bridge the structural gap when the action space changed.

03OPTIMIZATION

Algorithm details

An agent trainde as a proximal policy optimization PPO algorithm. PPO uses collected rollouts and a clipped policy objective to limit the huge updates/steps in parameter space, because the critic should be updated with the same or very close (that is defined by proximity bounds) policy that the actor collected rollouts. The actor provides mean valuse for actions giving observations, to ensure exploration output actions are sampled from normal distribution parametrized by actors output. A separate critic estimates value for advantage estimation. This is an optimization mechanism, that is responsible for NN parameters update.

25inputs→128 × 128tanh hidden layers→4motor commands

An actor and a critic are separated, each contains 20,356 parameters. Keeping these counts separate matters when estimating inference cost. The supplied configuration uses a fixed policy log standard deviation of −1.5.

The configured success condition combines pointing error below 1°, rate error below 0.01 rad/s, and a 1-second dwell. This is an evaluation condition, not a reconstruction of the reward.

The reward is a complex function that consists of: attitude_error, attitude_error_progress, rate, action_smoothness, wheel speed, target_success and other components.

Algorithm background: Schulman et al., Proximal Policy Optimization Algorithms.

04CURRICULUM / SCENARIOS

Curriculum learning: increase difficulty gradually

Even if imitation learning is helpful, while moving beyond simple motor control in hold position scenario it's not trivial for an agent to learn a complex follow a moving target (while influenced by external disturbances) from scratch. A curriculum learning turns out to be an effective tool right for this job. Training commences from a simple(intermediate) target and complexity adjusted by axis. Training development progressed from easier fixed-angle alignment task to wider initial-attitude distributions. Nonzero initial angular rates, random wheel interruptions can be admix in different proportions. Finally following a moving ground-station reference can be achieved through a number of small intermidiate tasks. Changing one source of difficulty at a time also helps distinguish an exploration problem from a broken estimator or a control-authority limit.

Sensor timing, motor nonidealities, and stochastic faults make the environment more demanding. Realism and domain randomization are different: modeling a disturbance does not establish that its parameters were randomized. The exact distribution of each randomized quantity belongs in the experiment record.
