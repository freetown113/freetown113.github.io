Research engineering project · space robotics

Learning to control
satellite's attitude.

Tetrahedral configured reaction wheels. Set of delayed sensors. Loss of signal/control. Motor limits. RL agent learns to control satellite's attitude to accomplish various scenarios.

This project is aimed to build a satellite attitude determination and control system (ADCS), connecting reinforcement learning with state estimation, fault handling, mission guidance, state supervison.

The principal question

Can a policy control
what it cannot directly observe?

The simulator knows the true state and the faults it injects. The controller receives a different view: estimated attitude, delivered wheel-speed measurements and estimated wheel health. Learning to act from this incomplete information is an important part of the project.

The policy commands the wheel motors. Other modules decide where to point, estimate the state and respond to health problems. I explain these connections step by step in the articles.
